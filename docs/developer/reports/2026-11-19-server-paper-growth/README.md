## 对 API 分类的含义

过去每轮 200 篇明显低于近期约 500–1,150 篇的常见有新增日规模，可能积压。因此取消默认篇数上限，按小批队列、逐篇串行处理更合适；原始库全量历史仍不重分类。

按 [11 月 18 日的 10 篇实测](../2026-11-18-deepseek-classification-benchmark/README.md) 线性折算，876 篇约需要 **16.5 分钟 API 处理时间**，空闲时段约 **0.80 元**；项目按高峰单价保守记账约 **1.60 元**。这不含采集、发布、重试、网络排队，缓存命中情况不同也会改变费用，不能当作付费承诺。

默认每日 1 元金额保护可能在处理完全部新论文前暂停，即使篇数、请求数和 Token 数均不设上限。此统计没有提高金额预算或发起付费分类。

服务器当前实际入库量受既有采集与筛选规则影响；启用 API 模式并取消关键词预过滤后，候选数量可能增加，不能假定未来一定稳定在 876 篇。应继续记录分类队列新增数、处理数、待处理数和实际 Token 用量。
