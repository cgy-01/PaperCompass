# 用户文档

这里介绍如何使用 Paper Compass 网站和 MCP。直接打开 [Paper Compass](https://papercompass.cn)，即可开始了解产品并进入研究工作区。

| 手册 | 你可以了解 |
| --- | --- |
| [账号与文献库](ACCOUNT_USER_GUIDE.md) | 使用 GitHub 登录、收藏论文、标记已读、跨设备同步，以及导入当前浏览器的文献记录 |
| [MCP 用户指南](MCP_USER_GUIDE.md) | 连接 Codex、Claude Code 等 Agent，用自然语言检索论文并阅读摘要 |

如果你主要使用网站，先看「账号与文献库」；如果希望让 Agent 帮忙调研，先看「MCP 用户指南」。
