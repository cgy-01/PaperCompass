# 账号与文献库

点击页面右上角的用户图标进入「我的账号」，选择「使用 GitHub 登录」，在 GitHub 授权后会返回 Paper Compass。

## 收藏和阅读记录

登录后，收藏与已读记录会保存到账号中；在其他设备登录同一 GitHub 账号，即可读取相同的文献库。打开论文详情会添加已读记录，点击星标可以收藏或取消收藏。

未登录时，文献记录继续保存在当前浏览器。清理浏览器存储可能移除这些本机记录。

## 导入原有记录

登录不会自动合并本机记录。在「我的账号」中点击「导入本机文献记录」，可将该浏览器保存的收藏和已读记录加入当前账号，重复条目会自动去重。

在共用设备上，导入前请确认这些本机记录属于自己。退出登录后，账号文献库不会写入未登录的本机文献库。

## 使用情况记录

Paper Compass 记录页面访问、按钮与论文点击、筛选、搜索次数和停留时间，用于分析产品使用情况。搜索词和输入框文字不进入行为记录；登录后的事件会关联平台账号，未登录事件使用浏览器标识。

行为明细按 90 天的默认保留策略分批清理，之后仅保留按天汇总的统计。具体保留天数以账号页面显示为准。收藏和已读记录独立保存，不随行为明细清理。

可在「我的账号」中关闭「允许记录此浏览器的产品使用情况」。该开关只影响当前浏览器，关闭后仍可正常登录、收藏和阅读论文。
