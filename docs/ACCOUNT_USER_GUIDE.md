# 账号与文献库

welcome 页面右上角的「登录」及各个工作区入口均直接连接 GitHub 授权，无中间登录页。未登录时先完成授权，已登录时直接打开目标页面。工作区右上角的账号入口可查看自己的文献记录。授权后会回到刚才的页面，论文详情或筛选条件会保留，无需另设 Paper Compass 密码。

如取消授权或登录超时，会返回 welcome 页面，可在提示中重试。GitHub 登录开放状态以页面显示为准。

## 我的账号

登录后，右上角显示 GitHub 用户名。账号页的「已收藏」「待阅读」「已读」均可直接打开对应文献列表；「返回研究工作区」会回到此前浏览的位置。

「已同步到账号」表示收藏和已读记录已成功读取。网络中断时会保留已加载的记录，点击「重新同步」可重试；登录过期时按提示重新登录，再继续保存。返回页面时会检查账号状态，也可随时主动同步。

## 收藏和阅读记录

登录后，收藏与已读记录会保存到账号中；在其他设备登录同一 GitHub 账号，即可读取相同的文献库。点击星标可以收藏或取消收藏；在论文详情中选择「标记为已读」，可将论文加入已读列表，也可以改回未读。

打开论文详情只会加入「最近浏览」，不会自动标记为已读。最近浏览保存在当前浏览器，最多保留 500 篇，登录账号和未登录状态分别保存。已有的已读记录会保留。

未登录时，文献记录继续保存在当前浏览器。清理浏览器存储可能移除这些本机记录。

## 导入原有记录

登录不会自动合并本机记录。在「我的账号」中点击「导入本机文献记录」，可将该浏览器保存的收藏和已读记录加入当前账号，重复条目会自动去重。

账号页只提示尚未导入的记录，也可选择「暂不导入」。导入中途失败时，已成功保存的部分会保留，再次点击会继续导入剩余记录。

在共用设备上，导入前请确认这些本机记录属于自己。退出登录后，账号文献库不会写入未登录的本机文献库。

点击「退出登录」后返回 welcome 页面，此浏览器原有的本机记录与账号中的收藏、已读均会保留。最近浏览只保存在当前浏览器；它与账号收藏、已读同步分别管理。

## 使用情况记录

Paper Compass 记录页面访问、按钮与论文点击、筛选、搜索次数和停留时间，用于分析产品使用情况。搜索词和输入框文字不进入行为记录；登录后的事件会关联平台账号，未登录事件使用浏览器标识。

行为明细按 90 天的默认保留策略分批清理，之后仅保留按天汇总的统计。具体保留天数以账号页面显示为准。收藏和已读记录独立保存，不随行为明细清理。

可在「我的账号」的「隐私与使用偏好」中关闭「允许记录此浏览器的产品使用情况」。该开关只影响当前浏览器，关闭后仍可正常登录、收藏和阅读论文。
